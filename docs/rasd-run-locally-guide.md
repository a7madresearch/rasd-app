# تشغيل تطبيق رصد على جهازك — دليل تفصيلي

هذا الدليل مكتوب على افتراض إنك ما عندك خلفية برمجية — كل خطوة موضحة بالتفصيل.
مبني لجهاز ويندوز، مع ملاحظات لماك حيث يختلف الأمر.

---

## الخطوة 1: تثبيت Node.js

Node.js هو البرنامج اللي يشغّل أدوات تطوير التطبيق على جهازك.

1. افتح المتصفح واذهب إلى: https://nodejs.org
2. راح تشوف زرين تحميل — اختر الزر المكتوب عليه **LTS** (يعني النسخة المستقرة الموصى بها). تجاهل النسخة الثانية (Current).
3. بعد التحميل، افتح الملف اللي نزل (.msi على ويندوز، .pkg على ماك).
4. راح يفتح معالج تثبيت (Setup Wizard) — اضغط **Next** بكل الشاشات، واترك كل الخيارات على وضعها الافتراضي (Default). ما تحتاج تغيّر أي شي.
5. بالشاشة الأخيرة اضغط **Install**، وبعدها **Finish**.
6. **أعد تشغيل الجهاز إذا طلب منك ذلك** — هذي خطوة مهمة، لأن ويندوز يحتاج يحدّث إعدادات النظام حتى يتعرف على الأمر الجديد.

**للتأكد إن التثبيت نجح:**
- على ويندوز: اضغط زر **Start**، اكتب `cmd`، واضغط Enter لفتح "Command Prompt".
- على ماك: افتح تطبيق **Terminal** (تجده بالبحث Spotlight، اضغط Cmd+Space واكتب Terminal).
- بالنافذة السوداء اللي فتحت، اكتب هذا الأمر واضغط Enter:
  ```
  node -v
  ```
- إذا ظهر شي مثل `v22.x.x` (أي رقم إصدار)، التثبيت نجح. إذا ظهرت رسالة خطأ مثل "not recognized"، أعد تشغيل الجهاز وجرّب مرة ثانية.

## الخطوة 2: تثبيت Git

Git هو البرنامج اللي ينزّل لك نسخة من كود المشروع من GitHub.

1. اذهب إلى: https://git-scm.com/downloads
2. اختر نظام تشغيلك (Windows أو Mac) وحمّل المثبّت.
3. شغّل الملف اللي نزل. راح تمر على عدة شاشات إعدادات — **اترك كل شي على الوضع الافتراضي واضغط Next** بكل شاشة، إلى أن تصل لزر **Install**.
4. بعد التثبيت اضغط **Finish**.

**للتأكد إن التثبيت نجح:**
- افتح نافذة Command Prompt / Terminal جديدة (نفس طريقة الخطوة السابقة).
- اكتب:
  ```
  git --version
  ```
- إذا ظهر رقم إصدار مثل `git version 2.x.x`، تمام.

## الخطوة 3: تثبيت تطبيق Expo Go على جوالك

هذا التطبيق يخلّي جوالك يشغّل نسخة تجريبية من "رصد" مباشرة بدون ما تحتاج تنزّله من متجر التطبيقات.

- **آيفون:** افتح App Store، ابحث عن **Expo Go**، وثبّته.
- **أندرويد:** افتح Google Play، ابحث عن **Expo Go**، وثبّته.

لا تفتحه الآن — بس خله مثبّت، راح نستخدمه لاحقاً.

---

## الخطوة 4: تحميل كود المشروع (Clone)

1. افتح Command Prompt (ويندوز) أو Terminal (ماك) — نفس الطريقة بالخطوة 1.
2. أول شي، اذهب لمكان تحب يكون فيه المشروع، مثلاً سطح المكتب:
   ```
   cd Desktop
   ```
   (`cd` تعني "غيّر المجلد الحالي إلى...")
3. حمّل نسخة من كود المشروع بهذا الأمر:
   ```
   git clone https://github.com/a7madresearch/rasd-app.git
   ```
   راح يطبع أسطر تدل إنه يحمّل الملفات. لما يخلص، راح تلقى مجلد جديد اسمه `rasd-app` بسطح مكتبك.
4. ادخل لمجلد التطبيق نفسه (مو المجلد الرئيسي، بل المجلد الفرعي `mobile`):
   ```
   cd rasd-app/mobile
   ```
   (على ويندوز أحياناً تحتاج `cd rasd-app\mobile` بدل الشرطة المائلة — إذا الأمر الأول ما اشتغل جرّب هذا)

## الخطوة 5: تثبيت مكتبات المشروع

وأنت لسا بنفس نافذة الـ Terminal وبمجلد `mobile`، اكتب:
```
npm install
```
هذا الأمر يحمّل كل "القطع الجاهزة" (Libraries) اللي التطبيق مبني عليها — Supabase، React Navigation، إلخ. راح ياخذ **دقيقة إلى ثلاث دقائق** حسب سرعة الإنترنت، وراح تشوف أسطر كثيرة تتحرك بالشاشة. هذا طبيعي.

**علامة النجاح:** لما يرجع لك السطر الفاضي جاهز لأمر جديد (يعني خلص)، وما فيه رسالة حمراء كبيرة تقول `ERROR` أو `npm ERR!` بالنهاية. تحذيرات صفراء (`npm warn`) طبيعية وتقدر تتجاهلها.

## الخطوة 6: إعداد مفاتيح Supabase

التطبيق يحتاج يعرف يتواصل مع أي مشروع Supabase — نفس اللي أنشأته وشغّلت عليه ملف الـ SQL.

1. لسا بنفس المجلد (`rasd-app/mobile`)، انسخ ملف الإعدادات النموذجي:
   - **ويندوز (Command Prompt):**
     ```
     copy .env.example .env
     ```
   - **ماك / إذا كنت تستخدم PowerShell أو Git Bash:**
     ```
     cp .env.example .env
     ```
2. افتح مجلد `rasd-app/mobile` بمستكشف الملفات (File Explorer / Finder)، ولاقي ملف اسمه `.env` (بدون امتداد، مو `.env.example`). إذا ما ظهر لك، فعّل خيار "إظهار الملفات المخفية" — بويندوز: بمستكشف الملفات اضغط تبويب View ثم فعّل "Hidden items".
3. افتحه بمفكرة النصوص (Notepad) — كليك يمين على الملف → Open with → Notepad.
4. امسح المحتوى، واكتب بدله سطرين بهذا الشكل (بدون قيم فعلية بعد):
   ```
   EXPO_PUBLIC_SUPABASE_URL=
   EXPO_PUBLIC_SUPABASE_ANON_KEY=
   ```
5. عبّي القيمتين من نفس المكان اللي جبتهم منه أول مرة: Supabase Dashboard → مشروعك → **Project Settings** → **API**:
   - انسخ **Project URL** وحطه بعد `EXPO_PUBLIC_SUPABASE_URL=` (بدون مسافة أو علامات اقتباس)
   - انسخ **anon public** key وحطه بعد `EXPO_PUBLIC_SUPABASE_ANON_KEY=`
   - (نفس القيمتين اللي أرسلتهم لي بمحادثتنا سابقاً — لو محفوظين عندك بمكان، انسخهم من هناك مباشرة)
6. احفظ الملف (Ctrl+S) وأغلقه.

⚠️ **لا تشارك ملف `.env` هذا مع أحد ولا ترفعه لـ GitHub** — رغم إن الـ anon key مصمم يكون بواجهة التطبيق فالمخاطرة منه محدودة، إلا إنه أفضل يبقى خاص بجهازك. الملف مُعدّ مسبقاً بإعدادات المشروع (`.gitignore`) حتى ما ينرفع لـ GitHub تلقائياً.

## الخطوة 7: تشغيل التطبيق

بنفس نافذة Terminal (تأكد إنك لسا بمجلد `rasd-app/mobile` — اكتب `cd` بدون شي واضغط Enter ثم تأكد من المسار، أو أعد فتح نافذة جديدة وسوّي `cd Desktop/rasd-app/mobile`):

```
npx expo start
```

**أول مرة تشغّله:**
- إذا طلب منك ويندوز إذن جدار الحماية (Firewall) — اضغط **Allow access** (السماح). هذا طبيعي، يحتاجه Expo حتى يتواصل مع جوالك عبر الشبكة.
- راح تشوف بالنهاية **رمز QR** (مربع فيه نقاط سوداء وبيضاء) مطبوع بالنافذة نفسها.

**اترك هذي النافذة مفتوحة طول وقت التجربة** — إذا سكّرتها التطبيق يتوقف عن الجوال.

---

## الخطوة 8: فتح التطبيق على جوالك

⚠️ **مهم جداً:** جوالك والكمبيوتر لازم يكونوا على **نفس شبكة الواي فاي** (نفس الراوتر).

- **آيفون:** افتح تطبيق **الكاميرا** العادي ووجّهه على رمز الـ QR اللي بالنافذة — راح تطلع لك إشعار بالأعلى "Open in Expo Go"، اضغط عليه.
- **أندرويد:** افتح تطبيق **Expo Go** اللي ثبّته بالخطوة 3، واضغط على زر مسح رمز QR (Scan QR Code) بداخله، ثم وجّهه على الرمز.

راح ياخذ التطبيق نصف دقيقة إلى دقيقة أول مرة يفتح (يحمّل الكود على جوالك). بعدها راح تشوف شاشة تسجيل الدخول لـ"رصد".

---

## الخطوة 9: تجربة التطبيق

بما إن كل مشروع يحتاج مالك + مقاول + استشاري، أنشئ 2-3 حسابات تجريبية (بريد إلكتروني مختلف لكل وحد) حتى تشوف الأدوار الثلاثة:

1. اضغط **إنشاء حساب جديد**، واختر الدور (مالك/مقاول/استشاري) لكل حساب.
2. سجّل دخولك كـ"مالك"، واضغط **+ مشروع جديد**.
3. بخانة اسم المقاول واسم الاستشاري، اكتب **بالضبط** نفس الاسم اللي سجّلوا فيه حساباتهم (هذي نقطة ضعف مؤقتة أشرحها بملف README — نتحسّنها لاحقاً).

## لو واجهت مشكلة

انسخ لي أي رسالة خطأ تظهر بنافذة الـ Terminal أو بالتطبيق نفسه بجوالك، بالضبط كما هي، وراح أساعدك تحلّها.

**مشاكل شائعة:**
- `'npm' is not recognized` أو `'node' is not recognized` → أعد تشغيل الجهاز بعد تثبيت Node.js (الخطوة 1)، وتأكد إنك سكّرت وفتحت نافذة Terminal جديدة بعد التثبيت.
- التطبيق بالجوال يعلق على "Connecting..." طويل → تأكد إن الجوال والكمبيوتر على نفس شبكة الواي فاي بالضبط (مو أحدهم على بيانات الجوال).
- رمز QR ما يفتح شي → تأكد إنك مثبّت Expo Go فعلاً، وجرب تفتحه وتمسح الرمز يدوياً من داخل التطبيق بدل الكاميرا.
