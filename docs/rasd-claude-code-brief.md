# تعليمات لـ Claude Code — بناء منصة رصد

انسخ النص التالي كامل وألصقه في Claude Code كأول رسالة، بعد ما ترفع معه الملفات الثلاثة:
`rasd-scope-requirements.md`, `rasd-database-schema.md`, `rasd-supabase-migration.sql`
(وممكن كمان `rasd-platform.jsx` كمرجع تصميم/تجربة استخدام).

---

## خطة العمل: ابدأ سحابياً، انتقل لجهازك لاحقاً

**المرحلة 1 — البناء الأولي (سحابي بالكامل، بدون تثبيت أي شي):**
1. أنشئ حساب GitHub مجاني (إن ما كان عندك)، وأنشئ مستودع (Repository) فاضي باسم `rasd-app`
2. افتح `claude.ai/code` من أي متصفح، اربطه بحساب GitHub، واختر المستودع
3. ارفع الملفات الأربعة (`rasd-scope-requirements.md`, `rasd-database-schema.md`, `rasd-supabase-migration.sql`, `rasd-platform.jsx`) للمستودع أول شي (عبر GitHub مباشرة أو تسألهم Claude يرفعها)
4. الصق التعليمات اللي بالأسفل كأول مهمة، وشغّلها

**المرحلة 2 — الانتقال لجهازك (لما تصير جاهز تكمّل محلياً):**
1. على جهاز الويندوز: `git clone` رابط المستودع
2. ثبّت Node.js وGit وClaude Code محلياً (بالخطوات اللي جهّزناها قبل)
3. كمّل الشغل بنفس المشروع بالضبط — كل الكود والتاريخ محفوظ بـ GitHub، ما راح يضيع شي

---

## النص اللي تنسخه لـ Claude Code (أول مهمة):

أبي أبني منصة اسمها "رصد" لمتابعة المشاريع الإنشائية، تجمع ثلاث أدوار: مالك، مقاول، استشاري. **المنصة لازم تكون تطبيق هاتف حقيقي يُنشر على App Store و Google Play** — مو موقع ويب.

المتطلبات الكاملة موثّقة بالملف المرفق `rasd-scope-requirements.md`، ونموذج البيانات موثّق بـ `rasd-database-schema.md`. جهّزت سكربت SQL كامل بـ `rasd-supabase-migration.sql` ينفّذ الجداول وقواعد الصلاحيات (RLS) على Supabase.

عندي أيضاً نموذج أولي (Prototype) بملف `rasd-platform.jsx` — استخدمه كمرجع للتصميم البصري (الألوان، الخطوط، أسلوب البطاقات) وتجربة الاستخدام لكل دور فقط، مو كأساس للكود، لأنه مبني بـ React (ويب) وأنا محتاج React Native.

**أبي منك تنفّذ التالي بالترتيب:**

1. أنشئ مشروع React Native جديد باستخدام Expo (TypeScript).
2. اربطه بمشروع Supabase (سأنشئ المشروع بنفسي على supabase.com وأعطيك المفاتيح، أو وجّهني للخطوات إذا احتجت شي مني).
3. نفّذ ملف `rasd-supabase-migration.sql` كـ migration على قاعدة البيانات.
4. ابني شاشات المصادقة (تسجيل دخول / إنشاء حساب) مع اختيار الدور (مالك/مقاول/استشاري) عند التسجيل.
5. ابني شاشة "مشاريعي" — قائمة بطاقات لكل مشروع المستخدم طرف فيه (لأن نفس المستخدم ممكن يكون بعدة مشاريع مختلفة، راجع القسم الخاص بهذا بملف النطاق).
6. ابني شاشات كل دور (مالك / مقاول / استشاري) مستوحاة من نفس الأسلوب البصري لملف `rasd-platform.jsx`، لكن مبنية بمكوّنات React Native ومربوطة ببيانات Supabase الحقيقية:
   - المقاول: نموذج تحديث المرحلة/نسبة الإنجاز/العقبات + التقاط صور فعلي من كاميرا الهاتف (expo-camera أو expo-image-picker) مع ملاحظات مرتبطة.
   - الاستشاري: تسجيل الزيارات، رصد الملاحظات وتوجيهها (لمقاول أو مالك)، اعتماد الإغلاق، الرد على الاستشارات (RFI).
   - المالك: لوحة تعرض نسبة الإنجاز (مخطط مقابل فعلي)، الملاحظات المفتوحة، الاستشارات، مع إمكانية رفع استشارة.
7. فعّل رفع الصور فعلياً عبر Supabase Storage (bucket: `site-notes-photos`، تم إنشاؤه بملف الـ SQL).
8. لا تبني إشعارات Push الآن (مو ضرورية بالمرحلة الحالية) ولا طبقة الذكاء الاصطناعي بعد — هذي آخر خطوة ورح نتفق عليها بعد ما تشتغل باقي المنصة صح مع بيانات حقيقية.
9. لما يوصل التطبيق لمرحلة جاهزة للاختبار، وجّهني لخطوات استخدام Expo Application Services (EAS Build) لبناء نسخة تجريبية أقدر أثبّتها على هاتفي مباشرة قبل ما نروح لمتاجر التطبيقات.

ابدأ بالخطوة 1، واشرح لي كل قرار تقني مهم تاخذه بشكل مختصر بينما تشتغل، لأني ما عندي خلفية برمجية عميقة.
